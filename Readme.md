# ⚡ Agentic Research Workspace (Frontend)

A modern, high-contrast Neo-Brutalist dashboard built with **React**, **Vite**, and **Tailwind CSS**. It serves as the user interface for the Autonomous Multi-Agent Research System, allowing users to execute research tasks, view live processing states, and display synthesized reports alongside automated Critic evaluations.

## 🎨 Key Features

- **Neo-Brutalist Design**: High-contrast borders, bold typography, hard drop-shadows, and responsive layout scaling.
- **Dual Input Processing**: Accepts standalone thesis research topics or specific URLs for target web scraping.
- **Structured Output Visualization**: Renders final synthesized research reports and critic feedback scores seamlessly.
- **Production Integration**: Connects via API calls to the FastAPI backend running on Render.

## 🛠️ Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
